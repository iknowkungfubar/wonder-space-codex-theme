# Wonder Space Dark for Codex

A community theme for the Codex view in the ChatGPT desktop app. It brings the deep indigo surfaces, lavender accents, and pale text of TheWonderSpace to the desktop app’s built-in theme importer.

| Color | Hex |
| --- | --- |
| Background | `#1b1730` |
| Text | `#e7e2f7` |
| Accent | `#a78bfa` |

The theme uses the app’s built-in Catppuccin code highlighting. The font preferences are Inter and JetBrains Mono, with system fallbacks.

## Import

1. Open [`wonder-space-dark.txt`](wonder-space-dark.txt) and copy the entire line, including the `codex-theme-v1:` prefix.
2. In the Codex view, open **Settings → Appearance** and select **Dark**.
3. Under **Dark theme**, choose **Import**, paste the line, and select **Import theme**.

The file contains only appearance settings. Import uses the app’s own controls and requires no installer, extension, or app patch. The built-in importer supports colors, fonts, and contrast. The starfield and animations belong to the original Obsidian theme. [OpenAI desktop appearance guide](https://learn.chatgpt.com/docs/app/settings#appearance)
